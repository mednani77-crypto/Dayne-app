# DeynBook Privacy Policy

**Effective date:** 1 September 2026  
**Version:** 1.0

DeynBook is an offline debt-recording application for individuals and small businesses. The app is designed so that ledger data stays on the user's Android device.

## Data handled by the app

Depending on what the user enters, DeynBook may store locally:

- Business or ledger name.
- Customer and supplier names.
- Optional phone numbers and notes.
- Debt and payment amounts, currencies, dates and descriptions.
- App language, theme and currency preferences.

## Data collection and transmission

DeynBook 1.0 does **not** operate an application server and does not transmit ledger data to the developer. It does not use advertising SDKs, analytics SDKs, cloud databases, Firebase, remote AI services, or account sign-in.

The Android manifest does not request the `INTERNET` permission. Android cloud backup is disabled for the application.

## Files created by the user

DeynBook can create statement PDFs, summary images, CSV exports and JSON backup files. These files are generated locally. They leave the app only when the user explicitly chooses a destination or shares them through Android's system UI.

When restoring a backup, DeynBook validates the file and creates a local safety copy of the current ledger before replacing data.

## Phone numbers

If a user stores a phone number and chooses the call action, DeynBook opens the Android dialer. DeynBook does not read the device contact list, call log or SMS messages.

## Financial-services disclaimer

DeynBook is a bookkeeping/recording tool. It is not a bank, lender, credit bureau, money-transfer provider or payment processor. The app does not provide loans, determine credit scores, transfer money or guarantee collection of debts.

## Data retention and deletion

Ledger data remains on the device until the user deletes individual records, deletes all app data from DeynBook, clears Android app storage, or uninstalls the app. User-created exported files remain wherever the user saved them and must be deleted separately by the user if desired.

## Children

DeynBook is a general bookkeeping utility and is not designed specifically for children.

## Changes

If a future DeynBook version introduces an online service or a third-party SDK that changes data practices, this policy and the Google Play Data Safety declaration must be updated before that version is released.

## Contact

The developer contact shown on the Google Play listing should be used for privacy questions.
